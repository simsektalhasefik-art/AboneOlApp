# 📱 AboneOl - Akıllı Abonelik & Ödeme Takipçisi

**AboneOl**, kullanıcıların dijital aboneliklerini (Netflix, Spotify vb.), spor salonu üyeliklerini ve düzenli faturalarını tek bir yerden takip etmelerini sağlayan **Local-First (Gizlilik Odaklı)** bir mobil uygulamadır.

---

## 🚀 Öne Çıkan Özellikler

* 📊 **Esnek Harcama Analizi:** Günlük, haftalık ve aylık ortalama harcama tutarlarını anlık hesaplama.
* 🗺️ **Ödeme Haritası (Timeline):** Ayın günlerine göre sıralanmış ödeme takvimi ve zaman çizelgesi.
* 🔗 **Tek Tıkla Abonelik İptali:** Global servislerin (Netflix, Spotify, Amazon Prime vb.) doğrudan resmi iptal sayfalarına yönlendiren derin bağlantılar (Deep Link).
* 🏷️ **Özel Kategori Ekleme:** Standart kategoriler dışında market, spor, kira vb. dilediğiniz özel kategoriyi tanımlama.
* 🛡️ **%100 Gizlilik & Güvenlik:** Kullanıcı verileri sunucuya gönderilmez, tamamen cihazın kendi yerel hafızasında (AsyncStorage) saklanır. KVKK ve BDDK kısıtlamalarına %100 uyumludur.

---

## 🛠️ Teknolojiler

* **Framework:** React Native (Expo)
* **Veri Depolama:** @react-native-async-storage/async-storage
* **İkon Seti:** @expo/vector-icons (Ionicons)
* **Tasarım:** Modern Dark Mode UI
